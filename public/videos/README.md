# Local Video Assets

Place your Veo 3 generated or downloaded MP4 videos here to use them as background themes. 

Please name them exactly as follows:
- `cozy-fireplace.mp4`
- `rainy-window.mp4`
- `calm-ocean.mp4`
- `forest-stream.mp4`

Each theme is configured with a beautiful pre-generated fallback image poster to ensure the UI looks great even while loading!
